# Scenario analysis for Indian equities

- Define horizon and the key value drivers.
- Build a base case from current reported financials and consensus only when sourced; do not invent consensus.
- Create bull and bear cases around measurable drivers: growth, margins, pricing, utilisation, capital intensity, credit costs, regulation, rates and valuation multiple.
- Show sensitivity tables when inputs are available and label assumptions.
- List catalysts, thesis breakers, downside risks and evidence that would change the scenario.
- Probabilities are optional; use them only when there is a defensible calibration or historical reference.
