# Agent evaluation

- Build representative tasks from real user workflows, including ambiguous requests and failure cases.
- Score correctness, completeness, tool selection, source grounding, safety, latency and cost separately.
- Use deterministic expected outcomes for calculations and file operations; use rubric-based review for open-ended tasks.
- Keep test data privacy-safe and avoid using private recordings or credentials as benchmark content.
- Compare providers on the same prompts, context, tools and evaluation criteria.
- Track regressions across model/provider changes. Do not equate eloquence with correctness.
