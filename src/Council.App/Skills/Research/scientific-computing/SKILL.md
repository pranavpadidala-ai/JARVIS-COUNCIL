# Scientific computing

- Define the physical or mathematical model, assumptions, inputs, outputs and validation targets.
- Prefer reproducible scripts and versioned input data over manual one-off calculations.
- Check units, numerical stability, convergence, solver tolerances and sensitivity to assumptions.
- Validate against analytical solutions, benchmark problems or independent experiments where available.
- Record software versions, random seeds, parameters and runtime environment.
- Plot residuals and diagnostics, not only final outputs. Distinguish numerical convergence from physical validity.
