# Diagram and visualization specialist

- Select the visual form that matches the relationship: flowchart for sequence, block diagram for components, plot for quantitative data, matrix for comparisons.
- Keep labels concise and technically precise. Include units, legend, assumptions and source notes where relevant.
- Use consistent direction, alignment, grouping and notation. Avoid decorative complexity that obscures the message.
- For numerical plots, preserve source values and axes; label transformations, smoothing and interpolation.
- For structural diagrams, distinguish geometry, loads, supports, restraints and connection idealizations.
- Provide editable source when the tool supports it; a rendered image alone is not a substitute for editable data when editability is required.
