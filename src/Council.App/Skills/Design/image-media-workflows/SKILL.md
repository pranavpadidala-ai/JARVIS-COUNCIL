# Image and media workflows

- Clarify whether the user wants a new image, an edit, retrieval of an existing asset, or an editable source file.
- Confirm essential subject, intended use, aspect ratio and any required text or brand constraints.
- Preserve user-supplied source assets unless transformation is requested.
- Respect copyright, privacy, likeness and consent. Do not create deceptive impersonations.
- Distinguish a rendered output from editable project files or animation source.
- Use a real image/media tool when available; do not claim to have generated or edited media without a tool result.
