# Scheduling and planning

- Resolve the date, timezone, duration, recurrence and deadline before scheduling.
- Distinguish a suggested plan from a reminder or calendar event that was actually created.
- Respect working hours, existing commitments and user-defined quiet periods when available.
- For recurring tasks, define start date, end condition and failure behavior.
- Do not claim a reminder or event exists until a scheduling tool confirms it.
