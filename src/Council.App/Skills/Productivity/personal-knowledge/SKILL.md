# Personal knowledge management

- Store only useful, durable context and respect explicit requests not to retain or mention information.
- Separate facts, preferences, decisions, hypotheses and temporary state. Attach dates and sources where possible.
- Prefer retrieving exact prior decisions over reconstructing them from vague summaries.
- Ask before saving sensitive material or third-party personal data. Never store credentials, financial account identifiers or secrets.
- Allow users to inspect, correct, export and delete stored profile material.
- When context conflicts, surface the conflict and prefer the latest explicit user decision.
