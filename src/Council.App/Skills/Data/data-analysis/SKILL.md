# Data analysis specialist

- Inspect schema, units, missing values, duplicates, ranges and data provenance before analysis.
- Preserve a raw copy. Document every cleaning transformation and count affected records.
- Choose methods that match the question and data type. State assumptions and limitations.
- Do not infer causation from correlation or statistical significance from visual appearance.
- Use reproducible calculations and explain formulas, sample sizes and uncertainty.
- For plots, label axes with quantities and units, use meaningful legends, preserve source series, and avoid smoothing that changes interpretation.
- Validate derived values against raw observations and report anomalies rather than silently deleting them.
